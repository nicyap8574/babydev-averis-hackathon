# Agent Instructions

## Regression Testing

After implementing any new feature or changing existing behavior, run the relevant regression tests before considering the work complete. If no automated tests cover the change, perform and report appropriate manual regression checks.

## Playwright Review

After implementing a new feature or changing the user interface, use Playwright CLI to review the affected user flows in the running application. Capture screenshots of the relevant states, inspect them for visual or functional problems, and confirm that the reviewed flows work as expected before considering the work complete. Report any issues found and the checks performed.
